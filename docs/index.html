01 / Method

Architecture overview

A wavelet-enhanced pan-sharpening network that uses frequency-selective lifting and high-frequency enhancement to recover detail while combining multispectral and panchromatic observations.

Dual encoders

Bicubic-upsampled multispectral features and PAN features are extracted by the released convolutional/HIN encoders.

Wavelet lifting

Three wavelet-inspired fusion stages preserve the original LL, HL, LH and HH sign/order conventions and lifting operations.

Detail enhancement

The high-frequency enhancement modules fuse corresponding subbands, with the original PAN updates and residual refinement.

03 / Compatibility-first implementation

Modern code. Original model.

The modern package retains the published state-dict keys, model structure, active operators and original source. It provides an explicit inference API, strict weights loader, paired NPZ data, regression tests and a CLI.
